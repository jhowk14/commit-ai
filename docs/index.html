Como funciona

terminal
$ commit-ai -c -s
🔄 Sincronizando alterações com a branch remota...
feat: add document parser route
✅ Commit criado: feat: add document parser route
$ commit-ai -s -c -b new-feature
🌱 Abrindo branch "new-feature"...

Instalação

bash
$ curl -fsSL https://raw.githubusercontent.com/jhowk14/commit-ai/v2.0.1/any-linux/install.sh | bash
$ commit-ai --setup

Baixa o binário nativo correto para a arquitetura e mantém sua configuração existente.

bash
$ paru -Syu --rebuild commit-ai
# Configure o provedor de IA
$ commit-ai --setup

O pacote AUR compila o binário Go localmente.

powershell
PS> irm https://raw.githubusercontent.com/jhowk14/commit-ai/v2.0.1/windows/install.ps1 | iex
PS> commit-ai --setup

O instalador baixa o .exe nativo e adiciona a pasta ao PATH do usuário.

⚙️ Configuração

Execute commit-ai --setup a qualquer momento para alterar suas preferências.

~/.commit-ai.conf
format=conventional
auto_confirm=false
ask_push=false
use_custom_prompt=false
provider=openai
model=gpt-oss-120b
openai_base_url=https://api.cerebras.ai/v1

Opções

-s, -S, --sync

Sincroniza antes do commit (stash, pull, pop e add)

-b, --branch

Cria ou troca a branch e envia após o commit

-c, --conv

Usa o formato Conventional Commits

-e, --emoji

Usa o formato Gitmoji

-m, --message

Fornece contexto adicional à IA

-p, --preview

Mostra a mensagem sem criar commit

-y, --yes

Cria o commit sem interação

--setup

Abre a configuração interativa

--config

Mostra a configuração sem revelar chaves

-u, --undo

Desfaz o último commit e mantém alterações preparadas

-C, --custom

Usa o arquivo de prompt customizado

--edit-prompt

Cria ou edita o prompt customizado
