How it works

terminal
$ commit-ai -c -s
🔄 Syncing with the remote branch...
feat: add document parser route
✅ Commit created: feat: add document parser route
$ commit-ai -s -c -b new-feature
🌱 Switching to branch "new-feature"...

Install in minutes

bash
$ curl -fsSL https://raw.githubusercontent.com/jhowk14/commit-ai/v2.0.7/any-linux/install.sh | bash
$ commit-ai --setup

Downloads the right native binary for your architecture and keeps your existing configuration.

⚙️ Configuration

Run commit-ai --setup whenever you want to change your provider, interface language, or push behavior.

~/.commit-ai.conf
format=conventional
auto_confirm=false
language=en
push_mode=ask
use_custom_prompt=false
provider=openai
model=gpt-oss-120b
openai_base_url=https://api.cerebras.ai/v1

CLI options

-s, -S, --sync

Sync before committing: stash, pull, restore, and stage.

-b, --branch

Create or switch a branch and push after the commit.

-c, --conv

Use the Conventional Commits format.

-e, --emoji

Use the Gitmoji format.

-m, --message

Give the AI extra context for a more accurate message.

-p, --preview

Preview the message without creating a commit.

-y, --yes

Create the commit without confirmation.

--setup

Open the interactive configuration flow.

--config

Show configuration without exposing API keys.

-u, --undo

Undo the latest commit while keeping changes staged.

-C, --custom

Use your custom prompt file.

--edit-prompt

Create or edit your custom AI prompt.
